Стек
    HTML + Tailwind CSS v4 (сборка через CLI)
    Ванильный JavaScript, без фреймворков
    Node.js LTS (20 и новее): нужен только для сборки CSS

Быстрый старт
    git clone https://github.com/lelekmarkova-arch/project-frontend.git
    cd project-frontend
    npm install
    npm run dev

Структура репозитория

project-frontend/
├── index.html         # разметка страницы
├── js/
│   ├── app.js         # меню, переключение тем и языка
│   └── translations.js  # словарь переводов RU/EN 
├── src/
│   └── input.css      # импорт Tailwind + переменные цветов для тем
├── dist/
│   └── output.css     # собранный CSS (генерируется; лежит в репозитории,
│                      # чтобы страницу можно было открыть без сборки)
├── images/
│   └── logo.png       # иконка вкладки
├── package.json
└── README.md

node_modules в репозиторий не входит, восстанавливается командой npm install.

Структура страницы
    Header (закреплён сверху): логотип, меню выбора темы (6 тем), выбор языка (RU / EN), кнопка «Войти»
    Main
        Hero: заголовок, подзаголовок, описание, две кнопки
        Секция из 8 карточек (сетка: 1 колонка на телефоне, 2 на планшете, 3 на ноутбуке)
    Footer: описание проекта и копирайт

Адаптивность на стандартных брейкпоинтах Tailwind. На экранах уже 640 px скрыты название логотипа и иконка глобуса, а меню тем растягивается на ширину экрана.
